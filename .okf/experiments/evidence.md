---
type: Rule
title: State what experiments actually measured
description: Avoid claiming retrieval quality from speed or generated fixtures.
tags: [experiments, metrics]
---

Engineering retrieval timings measure the local file engine. Agent-task pilots
measure harness feasibility. Neither establishes real-repository effectiveness.
Keep identical task-relevant facts across delivery methods and corpus sizes.

Use exact provider/runtime usage when reporting billed tokens. Peak logical
context requires actual request traces; file bytes are not a substitute.
Human equivalence audits and independent ratings remain pending until humans
perform them. Candidate authoring examples must retain that qualification.
