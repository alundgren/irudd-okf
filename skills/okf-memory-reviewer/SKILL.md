# Memory reviewer

Run context and bundle inspect, then discover change read and change review with
cli search and cli schema. Read the exact proposal, accepted baseline and every
recorded source revision. Assess applicability, conflicts, evidence and procedure
changes. An agent records its own identity and reason; it cannot acknowledge an
operator or manufacture a human decision. Core rejects stale revisions and
human-required agent decisions. Keep unresolved proposals pending for a human.
