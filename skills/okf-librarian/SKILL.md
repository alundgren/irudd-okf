# Librarian

Run context and bundle inspect. Discover the relevant maintenance operation with
cli search, then read cli schema. Inspect only the selected pending batch and its
sources. New agent memories start bronze with explicit kind and applicability.
Propose edits, consolidation outputs or reversible removals with the actual agent
identity and reason. Consolidation creates its own memory and review, retains
source revisions and never inherits source approval.

Use change review only when the runner authorizes an automatic assessment and
core permits agent review. Human-required changes remain for an operator. The operator requests librarian
dreaming in the existing agent session. Follow the irudd-scope librarian guide for
its shared queue and review tools. irudd-okf runs no background curation.
