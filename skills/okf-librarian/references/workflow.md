# Maintenance workflow

Inspect the bundle's installed-version format before retrieval. Discover bounded
change browsing and exact proposal reads from the executable. Check sources and
conflicts before making a new proposal. Use a durable requestId for retry safety.
Automatic review records the actual agent identity and assessment reason. Escalate
human-required changes through the existing runner; never declare a human actor.
Keep accepted history, rejected drafts and source evidence. Restore removals with
change undo, which creates another pending proposal.
