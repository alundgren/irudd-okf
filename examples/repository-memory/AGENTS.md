# Candidate repository memory locator

This example has not been established as an effective agent workflow. It is a candidate for controlled testing.

Repository guidance lives in `.okf/index.md`. Before working on a payment or GitHub access incident, read the matching incident concept. Apply guidance only to its stated repository and paths. If no matching concept exists, say so and inspect the affected code or tool output.

Capture a reproduced incident only after verifying a successful mitigation. Include the affected path, observed failure and verification command. Update an existing matching entry to avoid duplicates. Review the diff before publishing repository memory.
